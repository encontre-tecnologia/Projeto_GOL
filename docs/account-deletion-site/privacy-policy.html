Política de Privacidade

1. Dados que coletamos

  • Dados de conta: nome, e-mail e identificadores de usuário (login).
  • Dados de uso do app necessários para funcionalidades (ex.: lembretes, veículos e preferências).
  • Localização (quando autorizada por você) para recursos de localização no app.

2. Como usamos os dados

  • Autenticação e gerenciamento de conta.
  • Execução das funcionalidades principais do app.
  • Segurança, conformidade e prevenção de fraude.

3. Compartilhamento de dados

Podemos compartilhar dados com provedores de infraestrutura e serviços necessários para o funcionamento do app, como autenticação, banco de dados e backup, sempre conforme a finalidade do serviço e com medidas de segurança adequadas.

4. Armazenamento e segurança

Adotamos medidas técnicas para proteger os dados do usuário. Parte dos dados é armazenada localmente no dispositivo e parte em serviços em nuvem necessários para recursos de conta e backup.
